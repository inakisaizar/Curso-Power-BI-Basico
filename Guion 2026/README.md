# Curso de Power BI · Cámara de Gipuzkoa

Bienvenido al curso de iniciación a Power BI. Aquí tienes el material del curso: cada capítulo combina explicación, infografías y prácticas guiadas con los archivos de este repositorio.

## Antes de empezar: descarga los archivos

Todos los ejercicios usan archivos de este repositorio, guardados en la **misma ruta en todos los equipos**.

1. En la página principal del repositorio, pulsa el botón verde **Code > Download ZIP**.
2. Haz clic derecho sobre `Curso-Power-BI-Basico-main.zip` > **Extraer todo**.
3. Borra la ruta que propone Windows, escribe solo **`C:\`** y pulsa **Extraer**.
4. Comprueba que tienes la carpeta `C:\Curso-Power-BI-Basico-main\` y que dentro están directamente las carpetas de ejercicios.
